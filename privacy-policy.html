📋 ภาพรวม

Browser Pets เป็น Chrome Extension ที่แสดงสัตว์เลี้ยง AI เดินเล่นในหน้าเว็บ ผู้พัฒนา ไม่ได้รวบรวม บันทึก หรือส่งข้อมูลของคุณไปยังเซิร์ฟเวอร์ใดๆ ของตนเอง

ข้อมูลทั้งหมดถูกเก็บไว้ในอุปกรณ์ของคุณเท่านั้น หรือส่งตรงไปยัง AI Provider ที่คุณเลือกเอง

💾 ข้อมูลที่บันทึกในอุปกรณ์

Extension เก็บข้อมูลต่อไปนี้ในอุปกรณ์ของคุณเท่านั้น ผ่าน Chrome Storage API:

  • localAPI Key — บันทึกใน chrome.storage.local ไม่ sync ข้ามอุปกรณ์
  • syncการตั้งค่า — ตัวละคร, ภาษา, Provider, โมเดล, สถานะเปิด/ปิด

ข้อมูลเหล่านี้ไม่ถูกส่งออกนอกอุปกรณ์ ยกเว้นการ sync Chrome ปกติของ Google (เฉพาะ settings ทั่วไป ไม่รวม API Key)

🤖 ข้อมูลที่ส่งให้ AI Provider

เมื่อคุณใช้ฟีเจอร์ AI (ถามคำถาม / สรุปหน้าเว็บ / จัดกลุ่มแท็บ) Extension จะส่งข้อมูลต่อไปนี้ตรงไปยัง Provider ที่คุณเลือก:

  • ข้อความที่คุณพิมพ์
  • ชื่อหน้าเว็บและ URL ปัจจุบัน
  • เนื้อหาข้อความในหน้าเว็บ (เฉพาะตอนใช้ "สรุปหน้า")
  • รายชื่อแท็บที่เปิดอยู่ (เฉพาะตอนใช้ "จัดกลุ่มแท็บ")

การใช้งานข้อมูลนี้อยู่ภายใต้นโยบายของ Provider ที่คุณเลือก:

  • Anthropic (Claude) Privacy Policy
  • OpenAI Privacy Policy
  • Google (Gemini) Privacy Policy

🔐 สิทธิ์ที่ Extension ขอ

  • storage — บันทึกการตั้งค่าและ API Key ในอุปกรณ์
  • activeTab / tabs — อ่านชื่อแท็บสำหรับฟีเจอร์จัดกลุ่มและควบคุมสื่อ
  • scripting — แสดงตัวละครในหน้าเว็บ
  • tabGroups — จัดกลุ่มแท็บตามคำสั่ง AI
  • <all_urls> — แสดงตัวละครได้ในทุกหน้าเว็บ

👶 ผู้ใช้งานที่เป็นเด็ก

Extension นี้ไม่ได้มุ่งเป้าหมายไปที่เด็กอายุต่ำกว่า 13 ปี และไม่มีการรวบรวมข้อมูลส่วนบุคคลใดๆ โดยตั้งใจ

📋 Overview

Browser Pets is a Chrome Extension that displays AI pets walking around in your browser. The developer does not collect, store, or transmit your data to any servers they own.

All data stays on your device or is sent directly to the AI Provider you choose.

💾 Data Stored on Your Device

The extension stores the following data on your device only via the Chrome Storage API:

  • localAPI Key — stored in chrome.storage.local, never synced across devices
  • syncPreferences — selected pet, language, provider, model, enabled state

This data is never transmitted outside your device, except for Google's standard Chrome sync (preferences only — API Key is excluded).

🤖 Data Sent to AI Providers

When you use AI features (chat / summarize / group tabs), the extension sends the following directly to the provider you selected:

  • Your typed message
  • Current page title and URL
  • Page text content (only when using "Summarize Page")
  • Open tab titles and URLs (only when using "Group Tabs")

This data is governed by your chosen provider's privacy policy:

  • Anthropic (Claude) Privacy Policy
  • OpenAI Privacy Policy
  • Google (Gemini) Privacy Policy

🔐 Permissions Used

  • storage — save settings and API Key on your device
  • activeTab / tabs — read tab titles for grouping and media control features
  • scripting — inject the pet into web pages
  • tabGroups — group tabs as instructed by AI
  • <all_urls> — display the pet on any website you visit

👶 Children's Privacy

This extension is not directed at children under 13 and does not knowingly collect any personal information.
